## General Platform Notes

### itch.io
- All games support web browser play (HTML5)
- Preview GIFs/videos should be uploaded as screenshots
- Set browser viewport size to responsive or specific dimensions if needed
- Tag appropriately for discoverability

### GameMonetize
- Account required at https://gamemonetize.com
- Create game entry for each title to receive Game ID
- Configure Game ID in each game's `gm-config.js` before uploading
- Ads will display automatically after game over and between levels
- Monitor performance via GameMonetize dashboard
